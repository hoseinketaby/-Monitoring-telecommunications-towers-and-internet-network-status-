Telecom Tower Monitor - Network Log & Command Reference
=========================================================

این فایل فهرست دستورهای پیشنهادی برای بخش «Log and Command» اپلیکیشن
پایش دکل‌های مخابراتی است. دستورها را می‌توان با یا بدون / اجرا کرد.

راهنما
------
/help
نمایش فهرست دستورهای قابل اجرا.

/status
نمایش خلاصه وضعیت شبکه: تعداد تجهیزات، لینک‌ها و تجهیزات آنلاین.

/nodes
نمایش فهرست تجهیزات ثبت‌شده، نوع تجهیز و وضعیت آن.

/links
نمایش لینک‌های ارتباطی، نوع بستر، ظرفیت و فاصله لینک.

/ping <host-or-ip>
بررسی دسترسی یک دکل، روتر، سرور یا آدرس IP و نمایش زمان پاسخ.
مثال:
/ping 192.168.1.10
/ping tower-01.example.local

/curl <url>
ارسال درخواست HTTP برای بررسی سلامت API، سرویس مانیتورینگ یا تجهیزات شبکه.
مثال:
/curl https://example.com/health

/curl -I <url>
فقط نمایش Headerهای پاسخ HTTP (مناسب برای بررسی status code و latency).
مثال:
/curl -I https://api.example.com/health

/traceroute <host-or-ip>
نمایش مسیر شبکه تا مقصد برای پیدا کردن نقطه قطعی یا تأخیر.
مثال:
/traceroute 8.8.8.8

/dns <hostname>
تبدیل نام میزبان به IP و بررسی مشکل DNS.
مثال:
/dns tower-01.example.local

/port <host> <port>
بررسی باز بودن یک پورت TCP روی تجهیز مقصد.
مثال:
/port 192.168.1.10 443

/http-status <url>
نمایش فقط کد وضعیت HTTP مانند 200، 401 یا 503.
مثال:
/http-status https://api.example.com/health

/metrics [node-id]
نمایش شاخص‌های پایش تجهیز؛ مانند سیگنال، packet loss، دما، باتری
و کاربران متصل. در صورت وارد کردن node-id فقط همان تجهیز نمایش داده می‌شود.
مثال:
/metrics
/metrics tower-01

/events [critical|warning|all]
نمایش رخدادهای اخیر پایش و امکان فیلتر بر اساس سطح اهمیت.
مثال:
/events critical

/alerts
نمایش هشدارهای فعال، مانند قطعی برق، باتری بحرانی یا دکل آفلاین.

/add <type>
افزودن تجهیز جدید به توپولوژی.
typeهای مجاز:
tower, bts, microwave, fiber, router, core, power
مثال:
/add router

/connect <node-a> <node-b>
ایجاد لینک بین دو تجهیز موجود در توپولوژی.
مثال:
/connect bts-01 router-01

/disconnect <link-id>
حذف یا غیرفعال‌سازی یک لینک ارتباطی.
مثال:
/disconnect link-123

/analyze
تحلیل توپولوژی و نمایش تجهیزات ایزوله، مسیرهای ناقص و امتیاز شبکه.

/refresh
دریافت آخرین داده‌های دکل‌ها و به‌روزرسانی لاگ‌ها.

/clear
پاک‌سازی لاگ‌های نمایش‌داده‌شده در کنسول.

/export
خروجی گرفتن از لاگ‌های فیلترشده در فایل متنی.

/watch <seconds>
اجرای دوره‌ای یک بررسی تا زمان توقف کاربر.
مثال:
/watch 30

/stop
توقف عملیات دوره‌ای مانند watch.

نکات ایمنی
----------
1. دستورات شبکه را فقط روی تجهیزات و مقصدهای مجاز سازمان اجرا کنید.
2. برای curl، متدهای GET و HEAD را به‌صورت پیش‌فرض مجاز کنید؛
   متدهای تغییر‌دهنده مانند POST، PUT و DELETE نیازمند سطح دسترسی جداگانه باشند.
3. مقصدهای ping، dns، traceroute و port را در سمت سرور اعتبارسنجی کنید.
4. خروجی دستورات را محدود و زمان اجرای آن‌ها را timeout کنید.
5. کلیدهای API و رمز عبور را هرگز داخل لاگ ثبت نکنید.
6. برای هر دستور، زمان اجرا، کاربر و نتیجه موفق/ناموفق را ثبت کنید.
